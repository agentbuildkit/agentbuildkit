# AgentBuildKit 0.2.0

Prepared, not published. The public index still has `agentbuildkit` 0.1.0 and npm `agentbuildkit` 0.0.2.

## Packages

- `agentbuildkit` 0.2.0
- `agentbuildkit-templates` 0.2.0, requiring `agentbuildkit>=0.2.0,<0.3.0`
- npm bootstrapper `agentbuildkit` 0.0.3, independent of the Python versions

The upcoming install commands are in [Install](../install.md).

## What this release adds

Two supported templates can be installed as separate inactive teams: Customer Service and Operations Reporting. The installed team id is separate from the template id and the display name. Creation does not copy spreadsheet assignments or activate a revision. The same idempotency key with the same request returns the original team. A different name, description, template, or team id conflicts and leaves the original unchanged.

A draft is versioned. Validation and a scripted offline evaluation are bound to that exact content. Activation is explicit and publishes the revision. Later edits copy the active revision. Rollback is explicit. Published revisions are immutable. Saving or evaluating does not activate a team.

The local dashboard shows drafts, approvals, recovery, and the audit log for one operator. A pending approval can be recovered after a process restart. An action that already completed is not run again. An interrupted reservation stays unresolved and is not replayed. This is at-most-once reservation, not exactly-once delivery to an external system.

Local stdio MCP can list templates, create an inactive team, edit a draft, validate it, and run the scripted evaluation. MCP does not activate, roll back, run, approve, or connect an account. A draft created through MCP stays inactive until the dashboard activates it. Cancelling an evaluation does not store a pass.

Google Sheets is an optional extra. The connection is read-only, limited to `spreadsheets.readonly`, and scoped to one saved window. Composio is not installed by the default npm or Python install. Disconnect removes the local assignment and does not revoke Google access.

## Limits

This is one local operator. It is not hosted multi-user tenancy, remote MCP, or a cloud deployment.

A passing scripted suite does not measure a live model, does not prove that changed instructions are effective, and does not show that an account is ready.

Dashboard and MCP startup require POSIX `flock`. They fail with an actionable message on a platform without `fcntl`. Windows has not been verified for those commands. Harness commands that do not take that lock remain available.

The dashboard does not start a live model call by itself. A live run fails with a clear message when the provider credential is missing.
