# Archived consulting templates

These files are the private consulting playbook this repository used before it became AgentBuildKit. They are kept so the discovery, specification, and engagement steps are not lost.

They are not AgentBuildKit documentation. Paths such as `src/agent_platform` and `src/organisation` describe that older layout. The harness is now `src/agentbuildkit`. The customer-service team is `examples/customer_service`.
